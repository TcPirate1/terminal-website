https://tcpirate1.github.io/terminal-website/ is a website that I've been developing for almost a month now (24/09). I have yet to stream the process like I planned but it might be for the best as I do not feel like my brain is built for streaming. Progress may be slower than if I did stream or if I put all my focus on it but I find that's the beauty to this project. I am learning a new language and how to make a site without a framework, just a bundler (Vite) and using TypeScript because I do not like JavaScript. I could do the same in Python or another language but I am using Python professionally at the moment and other languages require too much of a setup that I spent way too much time, get tired and can't be bothered with the project anymore. Websites however, are easy to get started and sites like GitHub, GitLab and others provide ways to build and host the website without charging a fee for them. It also means I don't need to make a web server, a site generator or get my own domain name either and so from my perspective, there is a lot less setup.
I realize it isn't the 2000's but I am currently enjoying what I am doing with this and I haven't felt that in a while now so I will keep adding, fixing and working on this before it becomes too cumbersome.
